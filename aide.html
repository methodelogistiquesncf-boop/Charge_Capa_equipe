1. Dashboard de Pilotage

Le Dashboard est la vue direction de l'application. Il agrège toutes les données pour donner une vision synthétique de la charge, de la capacité et des arbitrages nécessaires.

Histogramme Charge / Capacité

Visualisation lissée des projets actifs avec socles cibles hachurés (MCO, Support, Transverse), ligne de capacité au premier plan, et export CSV.

📦 Synthèse Globale ETP

Indicateur principal : "+X ETP au total" pour tenir les échéances projets ET les cibles catégories combinés.

🔄 Rafraîchissement continu

Toutes les données du Dashboard sont recalculées automatiquement toutes les 2,5 secondes. Les chiffres affichés sont toujours à jour avec les dernières saisies.

2. Histogramme Charge / Capacité

🎨 Lecture visuelle

📊
Barres empilées colorées = projets actifs, lissés entre leurs dates début/fin. Chaque couleur = un projet différent.
▨
Socles hachurés en bas = charges cibles théoriques :
  • • Ambre = Support terrain (cible 0-15%)
  • • Violet = Transverse (cible 10-15%)
  • • Ardoise = MCO (cible 20-25%)
━
Ligne noire pleine (4px) avec halo blanc = capacité hebdo de l'équipe (ETP). Toujours au premier plan. Une barre qui touche ou dépasse cette ligne = semaine en surcharge.

🖱️ Interactions

  • Survol d'une barre : bulle tooltip affichant le détail des projets + Total agrégé (projets + cibles) + Capacité équipe + Delta (coloré vert/rouge).
  • Clic sur un projet dans la légende : mode solo → ce projet reste coloré, tous les autres (y compris les socles cibles) se grisent. Re-clic pour tout réafficher.
  • Clic sur MCO/Support/Transverse : mode solo sur la cible → seule cette cible reste visible, tout le reste se grise.

⚙️ Ajustement des cibles

Bouton "⚙️ Régler mes cibles" en haut à droite de la carte. Modifie les % cibles pour MCO, Support, Transverse, Projets.

💡 Dynamique : les socles hachurés se recalculent instantanément (sous ~2,5s) sans rechargement de page. Les valeurs sont mémorisées dans ton navigateur (localStorage).

📥 Export CSV

Bouton "📥 CSV" à côté du titre de la carte. Télécharge un fichier charge_projets_YYYY-MM-DD.csv compatible Excel (point-virgule, virgules décimales).

3. Carte Synthèse Globale ETP

Cette carte répond à la question : "Combien d'ETP faut-il pour tenir toutes les échéances projets ET les cibles catégories ?"

Les 4 indicateurs

Charge projets (échéances)
127,5 h/sem
Reste à faire lissé jusqu'aux dates de fin de chaque projet
Manque catégories
13,2 h/sem
Cibles MCO/Support/Transverse − réel (4 dernières semaines). Marges over-cible déduites.
Charge totale requise
140,7 h/sem
= Charge projets + Manque catégories
Capacité équipe
97,9 h/sem
= ETP × h/ETP/sem (ex: 4 × 24,5)

🎯 Lecture du résultat

+1,7 ETP au total
projets + catégories combinés
Formule : (Charge totale requise − Capacité équipe) ÷ Capacité d'1 ETP standard (24,5 h/sem)
Exemple : (140,7 − 97,9) ÷ 24,5 = 42,8 ÷ 24,5 ≈ +1,7 ETP

Interprétation :
  • • Positif → il faut recruter ou renégocier les échéances/cibles
  • • Négatif → tenable avec l'effectif actuel (marge disponible)
  • • Proche de 0 → équilibre précaire, moindre imprévu = surcharge

️ Modal explicatif

Clique sur le ⓘ en haut à droite de la carte pour ouvrir le modal détaillant chaque calcul, les hypothèses et les limites.

4. Vue Manager

📋 Tableau des enveloppes

Liste de tous les projets et catégories avec :

  • • Code, nom, catégorie (Projet / MCO / Support / Transverse)
  • • Priorité (P1 🔴 / P2 / P3 🟢) — ordre de tri et repère d'arbitrage
  • • Budget (heures et € via taux horaire paramétré)
  • • Consommé, Reste, % avancement
  • • Rythme (h/sem) et horizon (≈ semaines restantes)
  • • Jalons (cases cochées / total, prochaine échéance, retard)
  • • Actions : ✏️ Modifier, ⚪ Clôturer/Rouvrir, ✅ Checklist, 🗑️ Supprimer

📊 Courbe Charge / Capacité

Graphique montrant l'évolution de la charge vs capacité sur les semaines saisies. Lecture :

  • • ≤ 100% → maîtrisé
  • • 100-110% → tendu
  • • > 110% → surcharge avérée

👥 Consolidation par collaborateur

Vue individuelle de chaque agent : capacité réelle (ETP × rendement × facteur congés), heures saisies, taux C/C, répartition par catégorie.

5. Mon Planning (Agent)

Calendrier hebdomadaire

Vue semaine avec blocs colorés représentant les activités saisies.

➕ Saisie rapide (2 min/semaine)

  1. Copier la semaine précédente : bouton "📋 Copier semaine précédente" → tous les blocs de la semaine N-1 sont dupliqués en semaine N.
  2. Ajuster les blocs : modifier les durées, déplacer, supprimer les blocs qui ne s'appliquent plus.
  3. Ajouter un nouveau bloc : choisir la catégorie (Projet / MCO / Support / Transverse), le libellé, le jour, l'horaire, la durée.

🎨 Codes couleur des catégories

Projet : blocs rattachés à une enveloppe budgétaire
MCO : Maintien en Condition Opérationnelle (récurrent)
Support : support terrain, assistance
Transverse : activités transverses, réunions, formation

Fonctions gain de temps

  • • Copier la semaine type : duplique un modèle prédéfini (ex: semaine type d'un agent)
  • • Dupliquer un bloc : clic droit sur un bloc → "Dupliquer" → copie à la même heure le jour suivant
  • • Glisser-déposer : déplace un bloc d'un jour à l'autre, ou change l'horaire

6. Gestion des Utilisateurs (Admin)

Création de compte

  1. Aller dans l'onglet "Utilisateurs"
  2. Remplir : Nom, Email, Mot de passe (6 caractères min), Rôle (Agent / Manager / Admin), ETP, Rendement
  3. Cliquer sur "Créer"

⚠️ Erreur "Email déjà utilisé"

Si tu vois Firebase: Error (auth/email-already-in-use), c'est que l'email existe déjà dans Firebase Auth (compte supprimé de la liste mais pas de l'authentification).

Solution :

  1. Ouvrir Console Firebase → ton projet → Authentication → Utilisateurs
  2. Chercher l'email → supprimer le compte fantôme (menu ⋮ → Supprimer)
  3. Revenir dans l'app → recréer le compte

⚙️ Paramètres par utilisateur

  • • ETP : 1 = temps plein, 0.8 = 80%, 0.5 = mi-temps
  • • Rendement : part du temps contractuel réellement productive (défaut 0,85). Réglable ensuite dans le tableau Manager.
  • • Mode de saisie : " Saisit" (compte dans la charge) ou "🧭 Gestion seule" (exclu de la charge)

🔐 Rôles et droits

RôleDroits
🟢 AgentSaisit son propre planning. Voit sa capacité personnelle.
🔵 ManagerVue équipe, règle les rendements, gère enveloppes/priorités/checklists, accède au Dashboard.
🔴 AdminTout ce qui précède + création des comptes, ETP, paramètres annuels, référentiels.

7. FAQ & Problèmes courants

❓ Pourquoi je vois "0 h/sem" sur les projets au chargement ?

Résolu. Les calculs sont maintenant rafraîchis en continu (toutes les 2,5s). Si tu vois encore 0, attends 2-3 secondes ou recharge la page (Ctrl+Shift+R).

❓ Comment sont calculées les cibles MCO/Support/Transverse ?

Ce sont des % de la capacité totale de l'équipe, réglables via "⚙️ Régler mes cibles". Ex: MCO 20-25% × 97,9 h = 19,6-24,5 h/sem. Les socles hachurés dans l'histogramme montrent ces valeurs en temps réel.

❓ Pourquoi le "+X ETP" change quand je modifie les cibles ?

Le calcul de la Synthèse Globale inclut le "Manque catégories" (cibles − réel). Si tu augmentes une cible, le manque augmente → l'ETP total augmente. C'est normal : tu demandes plus de temps pour cette catégorie.

❓ Comment exporter les données pour la direction ?

Deux options :

  • Export CSV : bouton "📥 CSV" dans la carte Histogramme → fichier Excel avec toutes les semaines
  • Export PDF : bouton "️ Imprimer PDF" en haut du Dashboard → impression de toutes les cartes

❓ Les congés sont-ils pris en compte ?

Oui, automatiquement. La capacité réelle de chaque agent est réduite du facteur congés (jours travaillés ÷ jours ouvrés). Ex: 46 jours de congés/an → facteur 0,823. Les agents n'ont aucun congé à saisir.

❓ Pourquoi certaines semaines ont des barres très hautes et d'autres très basses ?

L'histogramme lisse les projets entre leurs dates début/fin. Si un projet a 100h de reste sur 4 semaines → 25h/sem. Si un autre a 100h sur 20 semaines → 5h/sem. Les pics = plusieurs projets qui se terminent en même temps.

❓ Comment interpréter le Delta dans la bulle tooltip ?

Delta = Total (projets + cibles) − Capacité équipe.

  • Positif (rouge) : surcharge → il faut lisser un projet ou renégocier une cible
  • Négatif (vert) : marge disponible → tu peux accepter plus de charge

❓ Les données sont-elles sauvegardées automatiquement ?

Oui. Chaque saisie est immédiatement envoyée à Firebase. Pas de bouton "Enregistrer". Si tu vois "Synchronisé" en haut à gauche, tout est sauvegardé.
