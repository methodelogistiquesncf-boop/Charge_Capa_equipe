🚀 Bien démarrer en 5 minutes

Cette application sert à dire où passent vos heures chaque semaine. Les données, accumulées semaine après semaine, deviennent l'argumentaire chiffré de l'équipe auprès de la direction : effectifs, surcharge, arbitrages, budgets projets.

🔑 Se connecter

1

Ouvrez l'application, saisissez email + mot de passe. « 🔑 Mot de passe oublié ? » envoie un email de réinitialisation.

2

Installez l'application : Android/Chrome → menu ⋮ → « Installer » · iPhone/Safari → Partager → « Sur l'écran d'accueil » · PC Chrome/Edge → icône ⊕ dans la barre d'adresse.

3

Chaque vendredi : ouvrez votre semaine, « ⧉ Copier semaine préc. » (ou « 📐 Copier semaine type » la première fois), ajustez 2-3 blocs, c'est terminé. 2 minutes maximum.

🎨 Les 5 catégories

🚀 Projets 🔧 MCO 🆘 Support terrain 📋 Transverse 🌴 Absences
  • Projets : activités rattachées à un budget (liste déroulante « Projet budgété »).
  • MCO : procédures, standards, support N2/N3, résolution d'écarts.
  • Support terrain : urgences, audits inopinés, troubleshooting.
  • Transverse : réunions, reporting, formation, veille.
  • Absences 🌴 : CP, RTT, formation, maladie… posées directement dans le calendrier pour proratiser la capacité.
📐 Semaine type vs semaines réelles

La semaine type est votre référence théorique (remplie une fois). Les semaines réelles sont celles saisies chaque vendredi. Toutes les statistiques équipe sont calculées sur le réel.

🌴 Absences = blocs violets

Posez une absence dans le calendrier (catégorie 🌴). La capacité de la semaine se réduit automatiquement (35 h − 7 h = 28 h). Zéro champ à remplir, zéro fausse « sous-charge ».

💰 Budgets projets

Chaque projet a une enveloppe d'heures. Quand vous posez un bloc 🚀 rattaché à un projet, les heures se débitent automatiquement. Alerte informative si le projet est déjà > 100 %.

🔒 Confidentialité

Un agent ne voit que son propre planning. Managers et admins voient l'équipe. Protection garantie côté serveur.

🟢 Votre mission : 2 minutes par semaine

Tout est sauvegardé automatiquement (☁️) : il n'y a aucun bouton « enregistrer » pour les blocs.

🗓️ La barre de semaine

  • ◀ ▶ : naviguer · « Aujourd'hui » : semaine courante · « 📐 Semaine type » : votre référence.
  • « ⧉ Copier semaine préc. » : recopie la semaine d'avant → base de départ chaque vendredi.
  • « 📐 Copier semaine type » : pour la toute première semaine réelle, part de votre référence.

🧱 Manipuler les blocs

➕ Ajouter

Clic sur un créneau vide (un « + » apparaît). Choisissez catégorie, projet/activité, jour, heure, durée.

✏️ Modifier / 🗑️ Supprimer

Clic sur un bloc coloré : la fenêtre s'ouvre avec tous les champs.

↔️ Déplacer

Glissez-déposez le bloc (souris) sur un autre jour / heure. Calage à la demi-heure.

⧉ Dupliquer

Deux méthodes :

  • Clic bloc → zone « ⧉ Dupliquer ce bloc vers… » : boutons jours ou « ⇉ Tous les jours ».
  • Ctrl + glisser (⌘ sur Mac) = copie.

🌴 Poser une absence

  • Cliquez un créneau vide → catégorie 🌴 Absences → libellé « CP », « RTT », « Formation »… → durée 7 h (= 1 jour).
  • La capacité de la semaine se réduit automatiquement (35 h − 7 h = 28 h).
  • Le message sous les totaux compare votre travail à la capacité réelle disponible — plus de fausse « sous-charge ».
  • Bonus : vous pouvez dupliquer le bloc sur les 5 jours en un clic (« ⇉ Tous les jours ») pour une semaine complète de CP.

💰 Travailler sur un projet budgété

  • Catégorie 🚀 Projets → liste déroulante « Projet budgété » → choisissez votre projet.
  • Les heures posées se débitent automatiquement du budget du projet.
  • ⚠️ Si le projet est déjà > 100 % du budget, un message informatif s'affiche (jamais bloquant) pour alerter le manager.
  • Vous pouvez aussi laisser « Hors budget » pour une activité projet non budgétée.
👀 Qui voit quoi ? Votre planning est visible par vous, et en lecture seule par managers/admins. Personne d'autre.

🔵 Votre mission : piloter, mesurer, arbitrer

Vous voyez tous les calendriers (lecture seule), la consolidation équipe, les budgets projets et le dashboard direction.

👤 Consulter les plannings

Onglet « Mon planning » → sélecteur en haut à droite → calendrier du collaborateur. Bandeau orange « Consultation seule » : vous ne modifiez pas ses blocs.

💰 Projets & budgets (votre section)

Gérez les enveloppes projets (code, nom, budget en heures, actif/clôturé). La consommation est calculée automatiquement depuis les blocs 🚀 posés par l'équipe.

  • ➕ Nouveau projet : code + nom + budget (h) + actif.
  • Consommé : total heures posées sur ce projet (tous agents, toutes semaines réelles).
  • Rythme : heures/semaine en moyenne depuis le début du projet.
  • Horizon : « ≈ X sem. rest. » = temps restant au rythme actuel avant épuisement.
  • État : 🟢 < 70 % · 🟡 70-90 % · 🟠 90-100 % · 🔴 > 100 % · ⚪ clôturé.
  • ⚪ / ♻️ : clôturer un projet terminé (il reste dans l'historique, ne disparaît pas).

Les agents voient automatiquement ces projets dans la liste déroulante « Projet budgété ». Si un projet est clôturé, il ne leur est plus proposé.

📋 Consolidation équipe

  • Période : mois, trimestre, année, 12 mois, tout.
  • 📈 Courbe charge vs capacité proratisée : capacité descend automatiquement les semaines de congés/RTT.
  • 🧮 Chiffres de période : semaines-agent saisies, taux de saisie, absences totales 🌴, charge moyenne, activité n°1.
  • Tableau par collaborateur : travaillé + absences + taux C/C proratisé.
  • « Où partent les heures ? » : agrégat par activité précise (hors absences).
📖 Lire le taux C/C : heures travaillées ÷ capacité disponible. ≤ 100 % maîtrisé · 100-110 % tendu · > 110 % surcharge.

📊 Dashboard direction

  • KPIs calculés sur le réel : capacité annuelle, charge projetée, taux de saturation, coût surcharge.
  • Courbe cumulée depuis janvier : bleue au-dessus de la verte = surcharge structurelle.
  • Bloc 💰 Budgets projets : 4 KPIs + top 5 consommés.
  • Recommandation automatique : ETP manquants + coût + alerte sur projets dépassés.
  • 🖨️ Imprimer PDF pour le CODIR.
🗓️ Rituel conseillé
  • Lundi matin : colonne « Semaines saisies » → relancer les manquants.
  • Fin de mois : période « Mois dernier » + budgets projets → PDF dashboard.
  • Objectifs : saisie ≥ 80 %, aucun projet > 100 % non justifié.

🔴 Votre mission : comptes, référentiels, paramètres

L'admin a tous les droits : utilisateurs, édition de tous les calendriers, référentiels, paramètres de calcul, purge.

👥 Onglet Utilisateurs

1

Créer un compte : nom, email, mot de passe temporaire (6 car. min), rôle → « Créer ».

2

Changer un rôle : 🟢 agent / 🔵 manager / 🔴 admin, effet immédiat.

3

Mode de saisie : « 📝 Saisit » = planning rempli + charge compte dans l'équipe · « 🧭 Gestion seule » = manager/admin pur : calendrier en lecture seule, exclu des stats.

4

Désactiver un compte : ✅ Actif → ⛔ Désactivé.

⚙️ Référentiels & paramètres (onglet Manager)

  • Référentiels : suggestions pour MCO, support, transverse, absences. Les projets sont gérés dans « 💰 Projets & budgets », pas ici.
  • Paramètres de projection : heures/semaine, semaines/an (47), ETP cible (référence direction), taux horaire. Ils pilotent tous les calculs : capacités, budgets en €, coûts.
  • 🗑️ Purger : supprime tous les blocs (double confirmation). Réservé aux tests.

❓ Questions fréquentes

🔑 Mot de passe oublié ?

Lien « Mot de passe oublié ? » sur l'écran de connexion → email de réinitialisation.

📲 Installer l'application ?

Android/Chrome : ⋮ → « Installer ». iPhone/Safari : Partager → écran d'accueil. PC Chrome/Edge : icône ⊕ dans la barre d'adresse.

🌴 À quoi sert la catégorie 🌴 Absences ?

À poser vos CP/RTT/formations/maladie directement dans le calendrier. La capacité de la semaine est alors proratisée automatiquement (ex : 35 h − 7 h = 28 h). Plus de fausse « sous-charge » dans les courbes.

💰 Comment les budgets projets sont-ils consommés ?

Automatiquement : chaque bloc 🚀 rattaché à un projet budgété débite l'enveloppe. Vous n'avez rien à faire de plus. Le manager voit la consommation en temps réel.

⚠️ Pourquoi un message « budget dépassé » dans la modale ?

Le projet choisi a déjà consommé > 100 % de son enveloppe. Le message est informatif (pas bloquant) pour vous inviter à prévenir votre manager.

⧉ Comment dupliquer un bloc ?

Clic bloc → « ⧉ Dupliquer ce bloc vers… » → boutons jours ou « ⇉ Tous les jours ». Ou Ctrl + glisser pour copier vers un créneau précis.

🧭 Pourquoi mon planning est-il en lecture seule ?

Compte réglé « 🧭 Gestion seule » par l'admin : vous pilotez sans saisir, vos heures ne comptent pas dans la charge équipe. Demandez le passage en « 📝 Saisit » pour contribuer.

👀 Qui voit mes semaines ?

Vous, et en lecture seule vos managers/admins. Personne d'autre.

☁️ Sauvegardé si je ferme l'onglet ?

Oui, chaque modification part immédiatement au serveur (badge « ☁️ Synchronisé »).

📴 Sans réseau ?

L'application installée s'ouvre hors connexion, mais lire/écrire les données nécessite du réseau.

🧮 Mon total de semaine n'affiche pas 35 h ?

Entre 34 et 36 h : cohérent. Très bas : blocs manquants (pensez transverse). Très haut : débordement. Semaine avec 🌴 : comparez au total « disponible » affiché.

🎯 Pourquoi tout ceci ? Chaque heure saisie alimente le dossier charge/capacité ET les budgets projets présentés à la direction. On défend les effectifs et les budgets avec des faits, pas avec un ressenti.
